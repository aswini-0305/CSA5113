CLASSICAL CIPHER C PROGRAMS

This folder contains five separate TXT files. Each file contains one complete C program.

1. 01_Monoalphabetic.txt
2. 02_Playfair.txt
3. 03_Polyalphabetic.txt
4. 04_HillCipher.txt
5. 05_Vigenere.txt

HOW TO USE:
1. Open the required TXT file.
2. Copy the C code.
3. Paste it into a new C source file in your compiler/editor.
4. Save the source file with a .c extension.
5. Compile and run it, then enter the requested input.

Note: The TXT files contain C source code as requested. They do not run by double-clicking as TXT files.
These are educational classical-cipher examples. Inputs are entered when the program runs.
